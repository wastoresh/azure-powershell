# Update-AzStorageDataShare

## SYNOPSIS
Update a Storage DataShare.

## SYNTAX

### UpdateExpanded (Default)
```
Update-AzStorageDataShare -AccountName <String> -Name <String> -ResourceGroupName <String>
 [-SubscriptionId <String>] [-AccessPolicy <IStorageDataShareAccessPolicy[]>]
 [-Asset <IStorageDataShareAsset[]>] [-Description <String>] [-Tag <Hashtable>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### UpdateViaIdentityExpanded
```
Update-AzStorageDataShare -InputObject <IStorageIdentity> [-AccessPolicy <IStorageDataShareAccessPolicy[]>]
 [-Asset <IStorageDataShareAsset[]>] [-Description <String>] [-Tag <Hashtable>] [-DefaultProfile <PSObject>]
 [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

### UpdateViaIdentityStorageAccountExpanded
```
Update-AzStorageDataShare -Name <String> -StorageAccountInputObject <IStorageIdentity>
 [-AccessPolicy <IStorageDataShareAccessPolicy[]>] [-Asset <IStorageDataShareAsset[]>] [-Description <String>]
 [-Tag <Hashtable>] [-DefaultProfile <PSObject>] [-AsJob] [-NoWait] [-Confirm] [-WhatIf] [<CommonParameters>]
```

## DESCRIPTION
Update a Storage DataShare.
